# ShewaCraft Furniture — Frontend

React + Vite storefront and admin UI.

See the [project README](../README.md) for setup, environment variables, and demo logins.

```bash
cp .env.example .env
npm install
npm run dev
```

Runs on `http://localhost:5173` and expects the API at `VITE_API_URL` (default `http://localhost:5000`).
